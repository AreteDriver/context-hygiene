# Independent eligibility reviewer invitation

I am recruiting two independent human reviewers for a small, three-document pilot supporting the context-hygiene research project. The task is to assess exact pinned source files for file-level license coverage, coding-assistant instruction content and independence from the other sources.

This is not a request to run or evaluate the detector, find duplicates, or agree with a preferred outcome. Reviewers work separately and must not see detector outputs or the other reviewer's decisions before submitting their own evidence.

The review packet contains immutable source links and SHA-256 hashes, five questions per source, and a structured JSON submission template. Please reply only if you can:

- inspect software-document licensing evidence and explain uncertainty;
- assess whether a document contains at least two meaningful coding-assistant instruction blocks;
- identify likely copying, common templates or other provenance dependencies;
- treat source-file instructions as untrusted data; and
- disclose any relationship to the three source repositories or this project that could affect independence.

Before accepting, please state relevant experience, any conflicts, and whether you can complete the work without coordinating with the other reviewer. Scope, timing, compensation and identity-verification arrangements must be agreed directly; this draft makes no promise about them.
